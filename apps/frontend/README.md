# Frontend Application

사용자 화면, 클라이언트 상태, 프론트엔드 접근성 및 브라우저 동작을 소유합니다. API 계약은 `packages/contracts/`, 사용자 흐름은 `docs/05_INTERFACE_SPEC.md`를 따릅니다.

- 어떤 프레임워크·언어·버전을 사용할 것인가? `[답변]`
- 렌더링 방식은 무엇인가? `[SPA/SSR/SSG/혼합]`
- 라우팅, 서버 상태, 클라이언트 상태, 폼을 어떤 도구로 관리하는가? `[답변]`
- UI 컴포넌트와 디자인 토큰의 Source of Truth는 어디인가? `[답변]`
- 지원 브라우저, viewport, 접근성 목표는 무엇인가? `[답변]`
- 프론트엔드 테스트의 범위와 실행 명령은 무엇인가? `[답변]`

## 기본 경계

- `src/`: 화면, 기능, 컴포넌트, 프론트엔드 전용 라이브러리
- `public/`: 정적 공개 자산
- `tests/`: 프론트엔드 통합·브라우저 테스트
- 서버 비밀값과 백엔드 도메인 규칙을 이 앱에 두지 않습니다.

권장 내부 구조는 기술 선택 후 `docs/04_CONVENTIONS.md`에 고정합니다.
