# Cross-Service Tests

여러 앱이나 외부 경계를 함께 검증하는 테스트를 둡니다. 앱 하나에만 속한 단위 테스트는 해당 앱의 `tests/`에 둡니다.

## 디렉터리

- `e2e/`: 사용자 관점의 전체 흐름
- `contract/`: 서비스와 외부 경계의 계약 호환성
- `integration/`: 여러 구성요소의 통합 동작
