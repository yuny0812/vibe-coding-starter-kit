## 작성 규칙

- 기능 요구사항: `FR-001`부터 시작합니다.
- 비기능 요구사항: `NFR-001`부터 시작합니다.
- 우선순위: `MUST`, `SHOULD`, `COULD`, `WONT`를 사용합니다.
- 한 요구사항에는 하나의 검증 가능한 의무만 적습니다.
- "빠르게", "직관적으로", "안전하게" 같은 표현은 측정 가능한 기준으로 바꿉니다.
- 각 요구사항은 `docs/03_ACCEPTANCE_CRITERIA.md`의 criteria와 연결합니다.
- 가능하면 EARS 패턴으로 작성합니다: `WHEN [트리거], 시스템은 [응답]해야 한다.`
- 조건부 동작은 `WHILE`, `WHERE`, 예외 동작은 `IF...THEN`을 사용해 조건과 결과를 분리합니다.
