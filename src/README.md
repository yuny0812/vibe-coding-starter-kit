# Single-Service Source

이 폴더는 CLI, 작은 자동화, 단일 런타임 서비스처럼 `apps/frontend`와 `apps/backend` 분리가 필요 없는 프로젝트에서만 사용합니다. 풀스택 프로필에서는 제품 코드를 `apps/`에 두고 이 폴더는 삭제할 수 있습니다.

## 프로젝트 시작 전 사용자가 답해야 할 질문

- 프로젝트가 정말 단일 서비스인가? `[답변과 근거]`
- 진입점과 공개 인터페이스는 무엇인가? `[답변]`
- 루트 `src/`를 사용할 때 삭제하거나 사용하지 않을 `apps/` 폴더는 무엇인가? `[답변]`
- 테스트는 루트 `tests/` 중 어디에 둘 것인가? `[답변]`

같은 책임의 코드를 루트 `src/`와 `apps/`에 중복 구현하지 않습니다.
