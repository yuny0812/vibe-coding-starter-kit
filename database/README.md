# Database Assets

데이터베이스 스키마 변경과 재현 가능한 seed 자료를 관리합니다. 실제 데이터와 비밀값은 저장하지 않습니다.

## 디렉터리

- `migrations/`: 순서가 보장된 스키마·데이터 변경
- `seeds/`: 비민감성 개발·테스트 초기 데이터

각 변경은 관련 요구사항, ADR, 배포·롤백 계획과 연결합니다.
