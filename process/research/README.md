# Research

이 폴더는 구현 전에 확인한 외부 자료, 기존 코드 조사, 실험 결과와 그 결론을 보관합니다. 승인된 최종 제품 지식은 `docs/`, 현재 코드베이스의 지속 사실은 `process/context/`가 Source of Truth이며, 이곳은 그 결론에 도달한 근거와 조사 이력을 남기는 곳입니다.

## 언제 작성하는가

- 기술·라이브러리·서비스를 비교하거나 새 의존성을 검토할 때
- 기존 코드의 동작, 제약, 장애 원인을 조사할 때
- 구현 방향을 바꿀 수 있는 가설이나 실험이 있을 때
- 외부 문서·논문·이슈·벤치마크를 근거로 결정을 내릴 때

단순한 파일 위치 확인이나 코드에 바로 드러나는 사실은 별도 리서치 문서를 만들지 않습니다.

## 파일 규칙

- 파일명: `YYYY-MM-DD-<topic>.md`
- 하나의 문서는 하나의 질문 또는 의사결정 범위를 다룹니다.
- 비밀값, 개인정보, 라이선스상 재배포할 수 없는 원문은 저장하지 않습니다.
- 외부 자료는 전체 복사 대신 제목, 링크, 확인일, 필요한 요약만 남깁니다.
- 결론이 제품 요구사항·아키텍처·운영 규칙을 바꾸면 같은 변경에서 관련 `docs/`, ADR 또는 `process/context/`를 갱신합니다.
- 구현으로 이어지면 관련 계획과 `process/diffs/` 기록에서 이 문서를 링크합니다.

## 상태

- `draft`: 조사 중
- `concluded`: 결론과 영향이 정리됨
- `superseded`: 더 최신 리서치나 결정으로 대체됨
