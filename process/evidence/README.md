# Verification Evidence

완료 선언을 뒷받침하는 테스트, 리뷰, benchmark, 스크린샷, 수동 검증 기록의 위치를 관리합니다. 비밀값, 개인정보, 대용량 원본 데이터는 저장하지 않습니다.

## 프로젝트 시작 전 사용자가 답해야 할 질문

- Git에 보관할 증거와 CI·외부 도구 링크로만 남길 증거는 무엇인가? `[답변]`
- 스크린샷·로그의 민감정보 제거 기준은 무엇인가? `[답변]`
- 증거 파일의 이름과 보존 기간은 무엇인가? `[답변]`

각 증거는 계획 경로, AC ID, 실행 환경, 일시를 식별할 수 있어야 합니다.

릴리스 전에는 `RELEASE_CHECKLIST.md`를 복사해 각 항목을 `확인`, `해당 없음`, `미확인` 중 하나로 닫습니다. `미확인`이 남아 있으면 자동으로 통과시키지 말고 사용자에게 목록과 영향을 제시합니다.
